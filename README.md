# GYM

Aplicación web personal para registrar entrenamientos de gimnasio.

## Funciones
- Seis grupos musculares: Pecho, Espalda, Piernas, Brazos, Hombros y Fullbody.
- Ejercicios sugeridos y posibilidad de agregar ejercicios propios.
- Registro de peso y repeticiones por serie.
- Historial con opciones para repetir, editar y borrar sesiones.
- Resumen de entrenamientos, series, peso máximo y volumen registrado.
- Exportación e importación de copias de seguridad en JSON.
- Almacenamiento local mediante IndexedDB. No requiere cuenta ni servidor.

## Ejecutar
Abrí `index.html` en un navegador moderno o publicá el repositorio con GitHub Pages.

## Publicar con GitHub Pages
En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**. Elegí la rama `main` y la carpeta `/ (root)`, luego guardá.

## Importante sobre tus datos
Los entrenamientos quedan en el navegador y dispositivo donde usás la app. No se sincronizan automáticamente entre dispositivos ni se guardan en GitHub. Descargá periódicamente una copia JSON desde el botón de la esquina superior derecha.
